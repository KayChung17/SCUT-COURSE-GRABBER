# 华工自主选课助手

这是一个运行在华南理工大学自主选课页面上的浏览器扩展。扩展使用当前浏览器的登录状态，不保存账号密码，也不处理统一身份认证。

## 安装扩展

1. 登录教务系统，进入自主选课页面
2. 打开 Chrome 或 Edge 的扩展管理页，开启“开发者模式”。
3. 点击“加载未打包的扩展程序”，选择本项目目录
4. 返回自主选课页面并刷新。页面右侧出现“选课助手”面板后，扩展加载完成。

扩展更新后，在扩展管理页点击“重新加载”，再刷新自主选课页面。

## 使用面板

### 添加课程

在“目标课程”输入框填写课程号或课程名称，点击“添加课程”。课程名称支持部分匹配，例如：

```text
元宇宙导论与实践
```

优先级数字越小越先尝试。展开“筛选与换课”可以设置：

- 时间筛选：多个关键词用逗号分隔，例如 `星期一,第1-2节`
- 教师筛选：多个关键词用逗号分隔，例如 `张三,讲师`
- 替换课程号：有空位时先退选指定课程，再尝试目标课程

### 开始抢课

1. 确认目标课程已经添加到监控列表。
2. 确认自主选课页面已经登录，并且能查询到目标课程。
3. 点击“开始抢课”。

脚本会定期查询课程列表、展开课程详情、识别教学班，并根据页面当前可用的“选课”按钮提交。部分选课轮次允许超过显示容量，脚本以页面选课控件是否可用为准，不只依据“已选/容量”数字判断。

遇到常见的二次确认选课框，脚本会继续处理确认流程。时间冲突、名额已被占用、登录失效或验证码等情况会记录在“运行日志”中。

### 定时启动

在“定时启动”中选择未来时间，点击“确定”。到达设定时间后，脚本会自动开始监控当前监控列表。定时启动前请保持页面登录状态和自主选课页面打开。

### 查看状态与调试

- “查看状态”：显示脚本是否运行、当前检查轮次、监控课程、成功课程和各课程尝试情况。
- “调试”：检查目标课程是否找到教学班、人数信息、页面选课按钮、筛选条件以及当前是否具备尝试条件。

结果会显示在面板内，并自动展开“运行日志”。

### 停止脚本

点击“停止”即可结束监控。浏览器刷新或关闭页面后，脚本运行状态会结束，课程配置也需要重新添加。

## 控制台备用脚本

`scutCourseGrabber.js` 是独立的控制台版本，扩展不会自动加载它。需要手动运行时：

1. 登录并打开自主选课页面。
2. 打开浏览器开发者工具的 Console。
3. 粘贴 `scutCourseGrabber.js` 的全部内容并执行。
4. 在脚本顶部配置 `TARGET_COURSES`，或在控制台传入目标课程：

```js
scutGrab.start([
  { code: '课程号', priority: 1 },
  {
    code: '课程名称',
    priority: 2,
    timeFilter: ['星期一'],
    teacherFilter: ['教师姓名']
  }
], 5000)
```

控制命令：

```js
scutGrab.status()
scutGrab.stop()
```

## 注意事项

- 只在本人已登录且有权访问的选课页面使用。
- 页面出现验证码、重新登录或风控提示时，先停止脚本并按页面提示人工处理。
- 脚本依赖教务系统当前页面结构，系统改版后可能需要更新选择器。
